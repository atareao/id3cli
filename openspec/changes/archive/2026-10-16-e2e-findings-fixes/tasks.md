# Tasks

Cada fix sigue RED (test que reproduce el bug, verificando que falla) → GREEN (fix mínimo) → REFACTOR (limpio) → e2e ampliado → cierre. Nada de `src/` ni `tests/` se toca antes del STOP del grupo 1.
